# DriveDirect

A car rental management system built with Flask. It manages cars, customers, rentals and maintenance.

## How to run
1. Install Python.
2. Open a terminal in this folder and run:

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

3. Open http://127.0.0.1:5000 in your browser, click **Create Account**, then log in.

The database (SQLite) is created automatically the first time you run it.
